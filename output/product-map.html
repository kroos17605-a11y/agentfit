AGENTFIT / PRODUCT MAP / V1

让 Agent 真正完成一次企业竞品调研

以“Claude Code 没有网页检索能力，但企业用户要调研竞品”为例，AgentFit 先核实宿主当前能力，再只补齐缺口，经过人类确认后交给宿主执行，并用质量门禁把结果闭环。

产品承诺用户只说想完成什么工作；AgentFit 找到最小可用能力路径，让宿主 Agent 执行，并检查交付物是否真的可用。

上下游交互

上游：企业用户、业务负责人、宿主 Agent 会话。
下游：网页 / GitHub 只读发现、MCP / Skill / plugin 安装边界、报告或 PPT 生成器、宿主文件系统。AgentFit 不替宿主调用工具，负责把能力路径和风险讲清楚。

为什么解决企业痛点

新人不需要先懂 MCP。AgentFit 把“我想做竞品调研”变成可解释的最小路径：先核实 Claude Code 到底有什么，再只补网页检索缺口，并在安装和执行前给人一个可控的决定点。

边界与信任

候选不是已安装能力；文件存在也不等于启用。未知 inventory 不触发盲搜。学习只记录抽象工作模式，质量门禁通过且用户接受后才提升复用优先级。
