# AgentFit 产品 Demo 与简历介绍

## Demo 目标

用一句自然语言展示 AgentFit 的核心价值：用户不需要知道 Skill、MCP 或插件的名称，只需描述工作目标，AgentFit 就能拆解任务、匹配现有能力、标记缺口，并把有序执行交给主 Agent。

## 运行 Demo

在项目根目录执行：

```sh
node scripts/product-demo.mjs
```

示例任务：`制作一份关于机器人行业最新发展的中文 PPT`。

Demo 会展示：

1. 交付物、时效和运行环境识别。
2. `research → evidence synthesis → PPT production` 的最小工作流。
3. 已安装 Browser 能力的复用，以及 Research/PPT 组件缺口的定位。
4. 每个步骤的输入、输出和 GitHub 搜索关键词。
5. 用户画像为机器人行业管理层时，推荐为何变得更垂直。
6. 安装确认和主 Agent 执行确认闸门。

Demo 使用离线固定目录，不下载或执行第三方项目；真实 GitHub 候选仍需在联网且获得用户确认后检索。

## STAR 简历描述

**S（情境）**：公司十几名刚开始使用 AI Agent 的办公用户不了解 Skill、MCP、Tool 和 Plugin，常用自然语言直接提出 PPT、调研、报告和数据分析需求，但产出经常不符合预期。

**T（任务）**：设计并落地 AgentFit，让用户无需学习工具生态，也能获得与任务匹配、可解释且可控的 AI 工作流。

**A（行动）**：将 AgentFit 嵌入 Codex、Claude Code 和 WorkBuddy；建立“交付物识别 → 任务拆解 → 宿主能力盘点 → 缺口搜索 → 用户确认安装 → 主 Agent 执行 → 质量检查 → 工作模式学习”的闭环；针对研究型 PPT 自动拆分研究、资料整合分析和可编辑 PPT 制作，并以工作流记忆持续细化后续推荐。

**R（结果）**：帮助公司十几名 AI 初学者用自然语言完成多类办公任务，降低工具选择和提示词门槛；通过能力复用、安装前确认和交付物质量检查，提升 AI 产出的可控性与一致性。项目核心测试 39/39、离线评估 9/9 通过。

### 一句话简历版

设计并实现嵌入 Codex、Claude Code 与 WorkBuddy 的 AgentFit 能力路由层，将自然语言办公需求自动拆解为可解释工作流，复用或推荐合适的 Skill/MCP/Plugin，并通过用户确认、主 Agent 执行和质量检查闭环，帮助公司十几名 AI 初学者稳定完成 PPT、调研、报告和数据分析任务。
