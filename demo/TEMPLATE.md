# Demo template source

This demo uses the page rhythm and responsive product-landing structure of [StructuredLabs/pagewald](https://github.com/StructuredLabs/pagewald) as a reference:

- License: Apache-2.0
- Source pattern: fixed navigation, split hero, feature sections, process walkthrough and closing CTA
- Adaptation: AgentFit-specific copy, workflow mockups, architecture map, memory loop, roadmap and interaction drawer

The Demo does not execute or import third-party template code at runtime. Its content and interaction logic are maintained in `index.html`, `styles.css` and `app.js`.
