# AgentFit Codex Plugin

This directory is the Codex plugin package.

- Plugin manifest: [`.codex-plugin/plugin.json`](.codex-plugin/plugin.json)
- AgentFit Skill: [`skills/agentfit/SKILL.md`](skills/agentfit/SKILL.md)
- Core scripts: [`skills/agentfit/scripts/`](skills/agentfit/scripts/)

The project-local Codex marketplace points to the packaged copy at `plugins/agentfit/`. Run `npm run package:adapters` after changing this adapter to refresh that copy.
