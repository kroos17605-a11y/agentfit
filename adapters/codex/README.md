# Codex Adapter

The Codex distribution is in [`agentfit/`](agentfit/).

- Manifest: [`agentfit/.codex-plugin/plugin.json`](agentfit/.codex-plugin/plugin.json)
- Skill instructions: [`agentfit/skills/agentfit/SKILL.md`](agentfit/skills/agentfit/SKILL.md)
- Local marketplace entry: [`../../.agents/plugins/marketplace.json`](../../.agents/plugins/marketplace.json)

`plugins/agentfit/` is the packaged copy used by the project-local Codex marketplace. Run `npm run package:adapters` to refresh it from this adapter.
